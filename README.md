# Wave Survival Arena

A UEFN + Verse learning project: a wave-based survival arena built to
explore the tools of Unreal Engine 6 (Verse and Scene Graph) inside
Unreal Editor for Fortnite.

## Approach
- Minimal reliance on legacy Fortnite devices
- Game logic built in Verse and Scene Graph
- UI/UX deferred to a later phase
- Final phase: refactor remaining devices into pure Verse
